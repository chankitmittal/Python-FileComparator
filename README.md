# 🔍 File Comparator Tool

A lightweight, standalone executable (`.exe`) tool built in Python for comparing files and visualizing differences. This tool allows you to quickly spot discrepancies between two files and export the comparison results into a clean, interactive HTML format. 

**No installation required—just download and run.**

---

## ✨ Key Features

- **Multi-Format Support:** Compare JSON, CSV, standard text files (`.txt`), and various source code formats (C, Python, JavaScript, C++, HTML, etc.).
- **Visual Differences:** Highlighting mechanism to clearly display additions, deletions, and modifications between the two selected files.
- **HTML Export:** Save your comparison results into a self-contained HTML file for easy sharing, archiving, or deep-dive reporting.
- **Zero Configuration:** Packaged as a standalone executable. No Python installation or external library setup is needed.

---

## 🚀 Getting Started

### Prerequisites
- Windows OS (since it is provided as a `.exe` file).
- No Python runtime or external dependencies are required.

### Installation & Usage
1. Go to the **Releases** section of this GitHub repository.
2. Download the `FileComparator_V.exe` file.
3. Double-click the downloaded executable to launch the tool.
4. Select your **Source File** (File 1) and **Target File** (File 2).
5. Click **Compare** to view the differences.
6. Click **Export to HTML** to save the formatted result locally.
